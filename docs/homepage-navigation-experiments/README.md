# Homepage Navigation Experiments

## Purpose
This experiment suite evaluates alternative category-navigation concepts for the James Progressive Solutions homepage hero and section integration.

The goal is to test distinct navigation paradigms, evaluate visual quality, implementation complexity, and mobile behavior, and select the optimal concept for final production implementation or future client work reuse.

## Concepts
1. **Category Deck (`experiment/category-deck`)**: An anchored 5-category deck layout maintaining immediate visibility of all categories with enhanced hierarchy for the CLarity project.
2. **Continuous Ribbon (`experiment/category-ribbon`)**: A single continuous category navigation band divided into 5 interactive category zones.
3. **Portal Tiles (`experiment/portal-tiles`)**: Distinct visual category portal tiles giving each category its own visual identity without relying on floating card overlays.

## Baseline & Workflow Rules
- All three concepts originate from the exact same baseline commit (`b9b536ef79d364937fdea16a7e803720183b9512`).
- The approved hero artwork, centered PS emblem, headline typography, and branding lockup remain the shared visual foundation across all branches.
- Implementation decisions and comparison results are documented in `DECISIONS.md` after visual review of each phase.
- Final production merge will occur only after comparing all three concepts.
